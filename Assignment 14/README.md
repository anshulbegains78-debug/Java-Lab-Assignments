# Assignment 14 – Characters: Counting and Positions

## 1. Experiment Title
Characters: Counting and Positions

## 2. Aim
To count vowels, count a specific character, and display character positions in a string using Java.

## 3. Software / Tools Required
- Java JDK
- Visual Studio Code (VS Code)
- VS Code Terminal

## 4. Theory
A string is a sequence of characters. Java provides the `charAt()` method to access a character at a particular index. A loop can be used to traverse a string and count characters.

## 5. Algorithm / Procedure

### Question 1
1. Initialize the string "programming".
2. Set count to zero.
3. Traverse each character using a loop.
4. Check whether the character is a vowel.
5. Increase count when a vowel is found.
6. Print the total count.

### Question 2
1. Initialize the string "programming".
2. Set target character to 'g'.
3. Traverse each character using a loop.
4. Compare each character with the target.
5. Increase count when they match.
6. Print the count.

### Question 3
1. Initialize the string "hello".
2. Traverse the string using a loop.
3. Print each character with its index using `charAt()`.

## 6. Input
- Question 1: programming
- Question 2: programming, target character g
- Question 3: hello

## 7. Output
- Question 1: Number of vowels: 3
- Question 2: Occurrences of g: 2
- Question 3: Position 0:h, Position 1:e, Position 2:l, Position 3:l, Position 4:o

Output screenshots are saved as `output.png` in their respective question folders.

## 8. Result
Successfully counted vowels and specific characters and displayed character positions using Java.
