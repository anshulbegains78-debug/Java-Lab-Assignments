# Assignment 15 – StringBuilder Methods

## 1. Experiment Title
StringBuilder Methods

## 2. Aim
To understand and perform append, delete, length, and insert operations using StringBuilder in Java.

## 3. Software / Tools Required
- Java JDK
- Visual Studio Code (VS Code)
- VS Code Terminal

## 4. Theory
StringBuilder is a mutable sequence of characters in Java. It allows modification of strings without creating a new object every time. Common methods include `append()`, `length()`, `deleteCharAt()`, and `insert()`.

## 5. Algorithm / Procedure

### Question 1
1. Create a StringBuilder with the text "Hello".
2. Append " World" using `append()`.
3. Display the resulting string.
4. Display its length using `length()`.

### Question 2
1. Create an empty StringBuilder.
2. Use a loop to append numbers 1 to 5, each followed by a comma.
3. Delete the last comma using `deleteCharAt()`.
4. Print the result.

### Question 3
1. Create a StringBuilder containing "Java".
2. Insert "Hello " at index 0 using `insert()`.
3. Print the resulting string.

## 6. Input
- Question 1: Hello
- Question 2: Numbers 1 to 5
- Question 3: Java

## 7. Output
- Question 1: Hello World, Length: 11
- Question 2: 1,2,3,4,5
- Question 3: Hello Java

Output screenshots are saved as `output.png` in their respective question folders.

## 8. Result
Successfully performed append, length, delete, and insert operations using StringBuilder in Java.
