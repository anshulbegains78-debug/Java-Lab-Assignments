# Assignment 2: Decisions and Loops with Numbers

## 1. Experiment Title
Decisions and Loops with Numbers

## 2. Aim
To understand decision-making statements, if-else conditions and loops in Java.

## 3. Software / Tools Required
- Java JDK
- Visual Studio Code (VS Code)

## 4. Theory
Decision-making statements are used to execute code based on conditions. Loops are used to repeat a block of code multiple times. Java provides if-else statements and for loops for these operations.

## 5. Algorithm / Procedure

**Question 1: Even or Odd**
1. Declare an integer variable n = 27.
2. Check whether n % 2 equals zero.
3. If true, print even; otherwise, print odd.

**Question 2: Grade Calculation**
1. Declare marks = 83.
2. Check marks using if-else-if conditions.
3. Print the appropriate grade.

**Question 3: Leap Year**
1. Declare year = 2024.
2. Check whether the year is divisible by 400, or divisible by 4 but not by 100.
3. Print Leap year or Not a leap year.

**Question 4: Factorial**
1. Declare n = 5 and factorial = 1.
2. Use a for loop from 1 to n.
3. Multiply factorial by each number.
4. Print the factorial.

## 6. Input

- Question 1: n = 27
- Question 2: marks = 83
- Question 3: year = 2024
- Question 4: n = 5

## 7. Output

**Question 1:**
27 is odd

**Question 2:**
Grade: B

**Question 3:**
Leap year

**Question 4:**
Factorial of 5 is 120

## 8. Result
All four Java programs were executed successfully and the expected outputs were obtained.
